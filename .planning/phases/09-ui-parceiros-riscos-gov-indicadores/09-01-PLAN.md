Follow the exact same pattern as `src/lib/api/etapas.ts` (created in Phase 8). Each function takes `(projetoId: string, ..., token: string)`, calls the appropriate endpoint, checks `response.ok`, throws on error, and returns `normalizeProjeto(await response.json())`.

**src/lib/api/parceiros.ts:**
1. `createParceiro(projetoId, data: { nome: string; papel?: string; status?: StatusParceiro }, token)` — POST `/:id/parceiros`
2. `updateParceiro(projetoId, parceiroId, data: { nome?: string; papel?: string; status?: StatusParceiro }, token)` — PUT `/:id/parceiros/:parceiroId`
3. `deleteParceiro(projetoId, parceiroId, token)` — DELETE `/:id/parceiros/:parceiroId`

**src/lib/api/riscos.ts:**
1. `createRisco(projetoId, data: { descricao: string; probabilidade?: ProbabilidadeRisco; impacto?: ImpactoRisco; mitigacao?: string; status?: StatusRisco }, token)` — POST `/:id/riscos`
2. `updateRisco(projetoId, riscoId, data: { descricao?: string; probabilidade?: ProbabilidadeRisco; impacto?: ImpactoRisco; mitigacao?: string; status?: StatusRisco }, token)` — PUT `/:id/riscos/:riscoId`
3. `deleteRisco(projetoId, riscoId, token)` — DELETE `/:id/riscos/:riscoId`

**src/lib/api/governanca.ts:**
1. `createDecisao(projetoId, data: { titulo: string; data: string; descricao?: string; responsavel?: string }, token)` — POST `/:id/decisoes`
2. `updateDecisao(projetoId, decisaoId, data: { titulo?: string; data?: string; descricao?: string; responsavel?: string }, token)` — PUT `/:id/decisoes/:decisaoId`
3. `deleteDecisao(projetoId, decisaoId, token)` — DELETE `/:id/decisoes/:decisaoId`

**src/lib/api/indicadores.ts:**
1. `createIndicador(projetoId, data: { nome: string; categoria?: string; series?: SerieDados[] }, token)` — POST `/:id/indicadores`
2. `updateIndicador(projetoId, indicadorId, data: { nome?: string; categoria?: string; series?: SerieDados[] }, token)` — PUT `/:id/indicadores/:indicadorId`
3. `deleteIndicador(projetoId, indicadorId, token)` — DELETE `/:id/indicadores/:indicadorId`

Import types from `../../types/projeto`. Import `API_URL` from `./base`. Import `normalizeProjeto` from `../../types/projeto`.
