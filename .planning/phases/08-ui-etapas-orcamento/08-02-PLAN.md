Create `src/components/supcdt/OrcamentoSection.tsx` that receives `{ projeto: Projeto; onUpdate: () => void }` and renders the Orcamento module section.

**Layout:** Same card pattern as EtapasSection:
- Outer: `overflow-hidden rounded-[1.35rem] border border-white/80 bg-white/80 shadow-sm`
- Header label "Financeiro" (sky-700/70) + title "Orcamento do projeto"
- "Nova rubrica" button in header (h-8 rounded-full, outline variant)

**Summary header (UIOB-01):** Below the header, render a 3-column stats row (similar to stats bar in DetalheProjeto):
- Compute totals from `projeto.rubricas ?? []`:
  - `totalPrevisto = sum of rubrica.previsto`
  - `totalExecutado = sum of rubrica.executado`
  - `saldo = totalPrevisto - totalExecutado`
- Display: "Previsto: R$ X", "Executado: R$ X", "Saldo: R$ X"
- Use `formatCurrency` from `../../lib/currencyUtils`
- Saldo text color: `text-emerald-600` if >= 0, `text-rose-600` if < 0

**Rubrica list (UIOB-02):** `divide-y divide-slate-100`. Each rubrica row shows:
- Nome (text-sm font-semibold text-slate-950)
- Proportional bar: width = `(executado / previsto) * 100`, capped at 100% for the bar. Use `bg-emerald-500` if ratio <= 1.0, `bg-rose-500` if > 1.0.
- Three values on the right: Previsto, Executado, Saldo (use formatCurrency, compact text-xs)
- Variation badge (UIOB-03): show percentage `(executado / previsto * 100).toFixed(0)%`. Color: `text-emerald-600 bg-emerald-50` if <= 100%, `text-rose-600 bg-rose-50` if > 100%. Handle previsto=0 edge case (show "N/A").
- Delete rubrica button (Trash2 icon), calls `deleteRubrica` then `onUpdate()`

**Collapsible aditivos (UIOB-04):** Each rubrica with `aditivos.length > 0` shows a toggle button "N aditivo(s)". On click, expand/collapse a sublist below the rubrica row showing each aditivo:
- Descricao, valor (formatCurrency), data (formatted if present)
- Use `useState` with a `Set<string>` of expanded rubrica IDs for toggle state
- Style: indented (pl-8), smaller text (text-xs), bg-slate-50 rows

**Adicionar aditivo (UIOB-05):** "+" button per rubrica (shown in the aditivos area). On click, show inline form with: descricao (text), valor (number), data (optional date input). On submit, call `addAditivo` then `onUpdate()`.

**Nova rubrica (UIOB-05):** Button in header. On click, show compact inline form at top of list. Fields: nome (text, required), previsto (number, default 0), executado (number, default 0). On submit, call `createRubrica` then `onUpdate()`.

Use `useAuth()` for token. Use `toast` from sonner for errors. Import Lucide icons: `Plus`, `Trash2`, `ChevronDown`, `ChevronRight`, `DollarSign`.
