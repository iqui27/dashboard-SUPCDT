const COLLECTION = 'projetos_supcdt';

**Helper interno (não exportado):**
```typescript
async function findProjectOrFail(id: string, res: Response) {
  if (!ObjectId.isValid(id)) {
    res.status(400).json({ error: 'ID de projeto inválido' });
    return null;
  }
  const db = await getDatabase();
  const col = db.collection<DBProjeto>(COLLECTION);
  const projeto = await col.findOne({ _id: new ObjectId(id) });
  if (!projeto) {
    res.status(404).json({ error: 'Projeto não encontrado' });
    return null;
  }
  return { col, projeto, oid: new ObjectId(id) };
}
```

**Endpoints de Etapas (ETAP-01 a ETAP-05):**

1. `POST /:id/etapas` (requireAuth) — ETAP-01
   - Body: `{ nome: string, percentual?: number, entregaveis?: { nome: string }[] }`
   - Valida `nome` obrigatório (retorna 400 se ausente)
   - Cria `DBEtapa` com `id: crypto.randomUUID()`, `percentual: body.percentual ?? 0`, `entregaveis` cada um com `id: crypto.randomUUID()` e `concluido: false`
   - Usa `$push: { etapas: novaEtapa }` no documento do projeto
   - Retorna o projeto atualizado completo com `res.json(updatedProject)` — buscar com `findOne` após update para retornar o doc fresh

2. `PUT /:id/etapas/:etapaId` (requireAuth) — ETAP-02
   - Body: `{ nome?: string, percentual?: number }`
   - Usa `$set` com dot notation: `etapas.$[elem].nome` e `etapas.$[elem].percentual`
   - `arrayFilters: [{ 'elem.id': etapaId }]`
   - Monta o `$set` dinamicamente — só inclui campos presentes no body
   - Se `matchedCount === 0`, retorna 404
   - Retorna projeto atualizado

3. `DELETE /:id/etapas/:etapaId` (requireAuth) — ETAP-03
   - Usa `$pull: { etapas: { id: etapaId } }`
   - Retorna projeto atualizado

4. `PATCH /:id/etapas/:etapaId/entregaveis/:entId` (requireAuth) — ETAP-04
   - Body: `{ concluido: boolean }`
   - Valida `typeof body.concluido === 'boolean'` (400 se inválido)
   - Usa `$set: { 'etapas.$[etapa].entregaveis.$[ent].concluido': body.concluido }`
   - `arrayFilters: [{ 'etapa.id': etapaId }, { 'ent.id': entId }]`
   - Retorna projeto atualizado

5. `POST /:id/etapas/:etapaId/entregaveis` (requireAuth) — ETAP-05 (adicionar)
   - Body: `{ nome: string }`
   - Valida `nome` obrigatório
   - Cria `DBEntregavel` com `id: crypto.randomUUID()`, `concluido: false`
   - Usa `$push: { 'etapas.$[etapa].entregaveis': novoEntregavel }`
   - `arrayFilters: [{ 'etapa.id': etapaId }]`
   - Retorna projeto atualizado

6. `DELETE /:id/etapas/:etapaId/entregaveis/:entId` (requireAuth) — ETAP-05 (remover)
   - Usa `$pull: { 'etapas.$[etapa].entregaveis': { id: entId } }`
   - `arrayFilters: [{ 'etapa.id': etapaId }]`
   - Retorna projeto atualizado

**Endpoints de Orçamento (ORÇA-01 a ORÇA-04):**

7. `POST /:id/rubricas` (requireAuth) — ORÇA-01
   - Body: `{ nome: string, previsto?: number, executado?: number }`
   - Valida `nome` obrigatório
   - Cria `DBRubricaOrcamentaria` com `id: crypto.randomUUID()`, `previsto: body.previsto ?? 0`, `executado: body.executado ?? 0`, `aditivos: []`
   - Usa `$push: { rubricas: novaRubrica }`
   - Retorna projeto atualizado

8. `PUT /:id/rubricas/:rubricaId` (requireAuth) — ORÇA-02
   - Body: `{ nome?: string, previsto?: number, executado?: number }`
   - Usa `$set` com dot notation e `arrayFilters: [{ 'elem.id': rubricaId }]`
   - Monta `$set` dinamicamente
   - Retorna projeto atualizado

9. `POST /:id/rubricas/:rubricaId/aditivos` (requireAuth) — ORÇA-03
   - Body: `{ descricao: string, valor: number, data?: string | null }`
   - Valida `descricao` e `valor` obrigatórios
   - Cria `DBAditivoRubrica` com `id: crypto.randomUUID()`, `data: body.data ? new Date(body.data) : null`
   - Usa `$push: { 'rubricas.$[elem].aditivos': novoAditivo }`
   - `arrayFilters: [{ 'elem.id': rubricaId }]`
   - Retorna projeto atualizado

10. `DELETE /:id/rubricas/:rubricaId` (requireAuth) — ORÇA-04
    - Usa `$pull: { rubricas: { id: rubricaId } }`
    - Retorna projeto atualizado

**Endpoint de Configuração de Módulos (MODU-01):**

11. `PATCH /:id/modulos` (requireAuth) — MODU-01
    - Body: `{ etapas?: boolean, orcamento?: boolean, parceiros?: boolean, riscos?: boolean, governanca?: boolean, indicadores?: boolean }`
    - Valida que pelo menos um campo boolean está presente no body (400 se vazio)
    - Constrói `$set` dinamicamente: para cada chave válida de `DBModulosAtivos`, se presente no body e `typeof === 'boolean'`, adiciona `modulosAtivos.${chave}` ao `$set`
    - Usa `updateOne({ _id: oid }, { $set: setObj })`
    - Retorna projeto atualizado

**Padrão de retorno para todos os endpoints:**
Após cada operação de escrita, fazer `findOne({ _id: oid })` e retornar o documento completo com `res.json(projeto)`. Isso garante que a resposta reflete exatamente o estado persistido.

**Tratamento de erro:**
Cada endpoint envolve o corpo em try-catch, logando o erro com `console.error` e retornando `res.status(500).json({ error: 'mensagem descritiva' })`.
